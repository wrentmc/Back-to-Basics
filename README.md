# Back to Basics
## A programming language written entirely in Python
This language, as referenced by its name, simulates programming in the early days of coding[^1]. It is interpreted.

## How to use
1) Head to the release page of this Repo and download the current release.
2) Write a BTB script (examples [here](https://github.com/wrentmc/Back-to-Basics/tree/main/examples)) using available commands (run `python3 btb.py -h` for help)
3) Run `python3 btb.py <your file>`

## Flags
Currently, BTB supports the following flags:
|Flag|Alias|Description|
|:---:|:---|---|
|-h|--help|show a help message|
|-c|--commands|show command list|
|-n|--notitle|do not show title|

[^1]: Obviously, it is much simpler than, say, assembly or COBOL.
